START HERE

1. Read README.md.
2. Install requirements: pip install -r requirements.txt
3. Run: python train.py
4. Verify dataset_metadata.json confirms >=500 rows and >=12 features.
5. Review model_comparison.csv; update README with the real results.
6. Run: streamlit run app.py

The actual test_data.csv and model/*.joblib files are generated when train.py runs.
This package intentionally does not fabricate test rows, model metrics, or a BITS Lab screenshot.
